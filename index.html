住環境ポテンシャル地図

U = Σ s·w·Φ

    対象範囲

    範囲— 面積—

    地図を動かして見たい地域を表示し、「表示中の範囲を対象にする」を押してください。広すぎると取得に時間がかかります（目安は 300 km² 以下）。

    通勤先（近いほど便利）

      追加した通勤先の印はドラッグで動かせます。

      OpenStreetMap から施設・道路・線路を取得し、ブラウザ内で計算します。

      データ

      保存した JSON は、次回ネットに接続せずに読み込めます。Python 版 potmap が出力した JSON も読み込めます。共有リンクには範囲・通勤先・重みが入ります（データは開いた人が取得します）。

      プリセット

      重み w と影響半径 r

      表示と補正

      ポテンシャルの谷（上位の候補地）

      最寄り駅Uスーパー通勤先
      まだ計算していません。「範囲」タブでデータを取得してください。

      地点の内訳

      地図をクリックすると、その地点のカテゴリごとの寄与が表示されます。

      データと限界

      • データを取得すると、件数と出典が表示されます。
      計算式
      U(x) = Σ_c s_c · w_c · Φ_c(x) Φ_c = 1 − Π_i (1 − exp(−|x−p_i|²/r_c²)) 点源（飽和） Φ_c = exp(−d_c(x)²/r_c²) 線源 Φ_work = exp(−|x−x_a|²/r²) s_c = +1（避けたい） / −1（便利） 斥力補正: +0.4·w_c·Φ_c(r=50m) 色は正負で別々に正規化（負側98%点、正側99%点）
